# 靜讀 QuietRead

一個極致的本地 TXT 閱讀器，與純 C 語言編寫的全局廣告攔截器（廣告殺手）。

## ✨ 核心特色

*   🪶 **極致輕量**：本體僅 **567 KB**，無廣告 SDK，不佔空間，拒絕臃腫。
*   🛡️ **物理超度**：基於本地 VPN 的 DNS 攔截模式，**0 伺服器，拒絕隱私洩露**。讓「廣告」連加載的機會都沒有。
*   ⚡ **純 C 核心**：底層 100% 由 C 語言手寫，後台實測 **0% 耗電**。
*   👻 **後台暗殺**：從多工介面划掉 App？沒關係，它依然會在背景默默守護你。
*   📖 **純淨閱讀**：附帶 TXT 小說閱讀器，支援夜間、純黑模式、音量鍵翻頁。
*   🆓 **完全免費**：不上架商店，不搞內購，純粹用愛發電。

## ⚠️ 安裝與權限說明（極度重要）

1.  **權限純潔**：本 App **僅需要「通知」權限**。如果你下載的版本要求讀取通訊錄、簡訊、定位等，那絕對是被惡意篡改了，請立刻刪除！
2.  **關於 VPN**：首次啟動需授予「VPN」權限，這是為了在本地建立虛擬網卡攔截 DNS 廣告，**所有流量都在手機本地處理，不會傳送到任何伺服器**。
3.  **關於無障礙**：需授予「無障礙服務」權限，這僅用於在瀏覽器中自動點擊關閉網頁彈窗（如 Edge、Chrome），絕不讀取您的任何輸入內容。
4.  **防殺後台**：強烈建議在系統設定中將本 App 設為「不受電池限制」，以免被 Android 系統的省電機制誤殺。
