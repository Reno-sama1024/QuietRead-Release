*   ⚡ **Pure C Core**: 100% hand-written in C. **0% battery drain** in the background.

## ⚠️ Installation & Permissions (Crucial)

1.  **Pure Permissions**: This app **only requires the "Notification" permission**. If a downloaded version asks for Contacts, SMS, or Location, it has been maliciously tampered with. Delete it immediately!
2.  **About VPN**: The "VPN" permission is required on first launch to create a local virtual network interface for DNS ad blocking. **All traffic is processed locally on your device and is never sent to any server.**
3.  **About Accessibility**: The "Accessibility Service" permission is only used to automatically click the close (X) buttons on web pop-ups (e.g., Edge, Chrome). It will absolutely never read or record your inputs.
4.  **Battery Optimization**: Highly recommended to set this app to "Unrestricted" in your system battery settings to prevent the Android system from killing it.
